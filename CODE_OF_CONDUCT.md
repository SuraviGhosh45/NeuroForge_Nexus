\# Code of Conduct



\## Our Standards



All contributors to NeuroForge Nexus are expected to:



\- Treat everyone with respect and professionalism.

\- Welcome constructive feedback and different perspectives.

\- Focus discussions on improving the project.

\- Communicate clearly and respectfully.

\- Respect other contributors' time and contributions.



\## Unacceptable Behavior



The following behaviors are not acceptable:



\- Harassment, discrimination, or personal attacks.

\- Threatening or abusive language.

\- Publishing someone else's private information without permission.

\- Deliberately disrupting project discussions or collaboration.

\- Any conduct that makes participation hostile or unsafe.



\## Reporting Issues



Report violations privately to the project maintainers through an

appropriate private communication channel.



For security vulnerabilities, follow the process described in

\[SECURITY.md](SECURITY.md). Do not disclose credentials or sensitive

security details in public issues.



\## Enforcement



Project maintainers are responsible for reviewing reports and

determining appropriate responses.



Responses may include a warning, removal of inappropriate content,

temporary restrictions on participation, or removal from the project

for serious or repeated violations.



\## Scope



This Code of Conduct applies to project spaces, issue discussions,

pull requests, code reviews, and other activities conducted on

behalf of NeuroForge Nexus.
